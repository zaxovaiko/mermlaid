Mermlaid

Mermaid diagrams, one shortcut away

Mermlaid renders Mermaid text into a diagram while you type, from a popover that hangs off your macOS menubar. Free, and open source under the MIT licence.

Press ⌘ ⇧ M anywhere, write or paste your Mermaid source, and copy or export the result as PNG, JPG or SVG.

Get it

  • Download on the Mac App Store
  • Builds on GitHub Releases — unsigned, so macOS will ask you to allow them the first time
  • Source on GitHub — build it yourself

Support

Found a bug, or something behaving oddly? The fastest route is opening an issue on GitHub — include your macOS version, the Mermlaid version from the About panel, and the diagram source if it is relevant.

Prefer email? Write to mermlaid@dyvertex.com. Expect a reply within a few days; this is a side project, not a support desk.

Privacy in one line

Mermlaid makes no network requests and collects nothing — everything renders on your Mac. The privacy policy spells that out.
